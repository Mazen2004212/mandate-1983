## Preparation

- [ ] `AGENTS.md` read.
- [ ] Narrative skill loaded.
- [ ] Relevant game-system skill loaded.
- [ ] World context inspected.
- [ ] Character context inspected.
- [ ] Prior events inspected.
- [ ] Future dependencies identified.
- [ ] Scene purpose identified.

## Originality

- [ ] Characters are original.
- [ ] Institutions are original.
- [ ] Conflict is original.
- [ ] Dialogue is original.
- [ ] Choices are original.
- [ ] No copied political-game terminology appears.
- [ ] No existing scene is disguised as an adaptation.

## Voice

- [ ] Every speaker sounds distinct.
- [ ] Professional vocabulary is credible.
- [ ] Public and private voices differ where appropriate.
- [ ] Generic AI phrasing is absent.
- [ ] Speakers do not explain shared knowledge unnecessarily.
- [ ] Cartoon-villain dialogue is absent.
- [ ] Sentence openings are not repetitive.

## Choice Quality

- [ ] Choices are distinct.
- [ ] Choices are meaningful.
- [ ] No obviously perfect choice exists.
- [ ] No joke option breaks tone.
- [ ] No false choice lacks narrative purpose.
- [ ] Requirements are valid.
- [ ] Consequences match wording.
- [ ] Uncertainty is fair.
- [ ] Player voice is consistent.

## Consequences

- [ ] Immediate narrative response exists.
- [ ] Political effect exists.
- [ ] Faction or regional effect exists.
- [ ] Character effect exists.
- [ ] Delayed effect exists.
- [ ] Media interpretation exists.
- [ ] Memories are defined.
- [ ] Follow-ups are defined.
- [ ] Ending relevance is defined where applicable.

## Continuity

- [ ] Political date is correct.
- [ ] Chapter is correct.
- [ ] Character office is correct.
- [ ] Character location is correct.
- [ ] Relationship status is correct.
- [ ] Death or imprisonment status is correct.
- [ ] War status is correct.
- [ ] Election status is correct.
- [ ] Constitutional status is correct.
- [ ] Known and hidden information are correct.
- [ ] No choice is referenced unless it occurred.

## Customized Names

- [ ] No first-family name is hard-coded.
- [ ] Approved tokens are used.
- [ ] Short names tested.
- [ ] Long names tested.
- [ ] Apostrophes tested.
- [ ] Hyphens tested.
- [ ] Unicode tested.
- [ ] Grammar remains natural.

## Content Rating

- [ ] Romantic characters are adults.
- [ ] Explicit sex is absent.
- [ ] Nudity is absent.
- [ ] Sexual violence is absent.
- [ ] Graphic gore is absent.
- [ ] Graphic torture is absent.
- [ ] Real-world operational crime instructions are absent.
- [ ] Sensitive-content warning exists where needed.
- [ ] Teen presentation is preserved.

## Media and Documents

- [ ] Outlet voice is correct.
- [ ] Confidence labels match evidence.
- [ ] Headlines are period-appropriate.
- [ ] Propaganda differs from factual reporting.
- [ ] Documents are readable.
- [ ] Legal and military language is plausible but not bloated.

## Technical Integration

- [ ] Scenario ID is unique.
- [ ] References resolve.
- [ ] State variables exist.
- [ ] Effects use valid ranges.
- [ ] Eligibility is possible.
- [ ] Follow-ups resolve.
- [ ] No circular mandatory chain exists.
- [ ] Delayed effects are defined.
- [ ] Family tokens validate.
- [ ] Content schema passes.

## Delivery Report

- [ ] Chapter reported.
- [ ] Scenario IDs reported.
- [ ] Characters reported.
- [ ] Choices reported.
- [ ] Consequences reported.
- [ ] Memories reported.
- [ ] Follow-ups reported.
- [ ] State references reported.
- [ ] Validation reported.
- [ ] Tests reported.
- [ ] Limitations reported.
- [ ] Skipped checks reported with reasons.

A narrative scene is not complete merely because its prose is readable.
Its choices, continuity, state integration, consequences, and future branches
must also be valid.
