## Character Identity

- [ ] Correct character
- [ ] Correct age
- [ ] Correct role
- [ ] Correct social background
- [ ] Correct personality
- [ ] Correct period
- [ ] Distinct from other characters
- [ ] No real-person likeness

## Face and Anatomy

- [ ] Eyes consistent
- [ ] Pupils aligned
- [ ] Teeth natural
- [ ] Ears natural
- [ ] Hairline plausible
- [ ] Neck and shoulders correct
- [ ] Hands correct where visible
- [ ] No duplicated features
- [ ] No blended accessories
- [ ] No deformed anatomy

## Expression

- [ ] Expression recognizable
- [ ] Expression restrained
- [ ] Identity preserved
- [ ] Age preserved
- [ ] Camera angle preserved
- [ ] Lighting preserved
- [ ] Clothing continuity correct

## Clothing and Accessories

- [ ] 1980s appropriate
- [ ] Role appropriate
- [ ] Fabric plausible
- [ ] Buttons and seams coherent
- [ ] Glasses coherent
- [ ] Jewelry coherent
- [ ] Medals coherent
- [ ] Insignia fictional
- [ ] No modern logo
- [ ] No modern device

## Composition

- [ ] 4:5 aspect ratio
- [ ] Master dimensions at least 1200 x 1500
- [ ] Safe crop preserved
- [ ] Face readable
- [ ] Head not clipped
- [ ] Chin not clipped
- [ ] Essential identifiers preserved
- [ ] UI space preserved
- [ ] Background restrained
- [ ] Lighting compatible with UI

## Style Consistency

- [ ] Matches the art bible
- [ ] Matches the contact sheet
- [ ] No style drift
- [ ] No duplicate face
- [ ] No lighting drift
- [ ] No scale drift
- [ ] No background drift
- [ ] No photorealistic outlier
- [ ] No cartoon outlier

## Technical

- [ ] Correct filename
- [ ] Correct path
- [ ] Correct format
- [ ] Correct dimensions
- [ ] File size acceptable
- [ ] No visible compression artifacts
- [ ] Metadata exists
- [ ] Prompt version recorded
- [ ] License status recorded
- [ ] Placeholder status correct

## UI Integration

Test:

- [ ] Dialogue desktop
- [ ] Dialogue mobile
- [ ] Cabinet
- [ ] Family setup
- [ ] Family page
- [ ] Dossier
- [ ] Election
- [ ] Ending
- [ ] Dark UI
- [ ] Paper UI
- [ ] 200% zoom

Check:

- [ ] No clipping
- [ ] No text overlap
- [ ] No important area hidden
- [ ] Face remains readable
- [ ] Correct alt behavior
- [ ] No layout shift
- [ ] No failed request
- [ ] No console error

## Approval Status

Choose one:

- [ ] Rejected
- [ ] Revision required
- [ ] Temporary placeholder
- [ ] Production candidate
- [ ] Approved
- [ ] Final
- [ ] Deprecated

Final requires:

- [ ] Rights status reviewed
- [ ] Technical review passed
- [ ] UI integration passed
- [ ] Responsive review passed
- [ ] Contact-sheet review passed
- [ ] No unresolved blocking defects
