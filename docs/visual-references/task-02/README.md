## Usage rules

Use these references for:

- Layout
- Visual hierarchy
- Material treatment
- Information density
- Lighting
- Atmosphere
- Component composition
- Government-document styling

Do not copy directly:

- Text
- Characters
- Portraits
- Statistics
- Decisions
- News
- Flags
- Emblems
- Signatures
- Exact ornament
- Real political or military symbols

All implementation must remain original and consistent with:

- MANDATE: 1983
- The Republic of Varenne
- `docs/STORY_BIBLE.md`
- `docs/MVP_SCOPE.md`

These files are design references only.

They must not be rendered directly inside the production application.

The visual language must be recreated using original React components,
accessible HTML, CSS, and original SVG ornament.
